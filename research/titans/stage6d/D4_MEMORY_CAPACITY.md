# D4 · Capacity and interference

Keep the two-layer residual MLP as the reference. A linear memory can fit
arbitrary targets on independent keys up to input rank in exact arithmetic.
The nonlinear Cell has no analogous capacity guarantee from parameter
count alone. Evaluate normalized geometry and association count separately.

For a small new-task gradient step, old loss change is approximately
−theta times the gradient inner product. Negative alignment predicts
interference. Momentum and shrinkage contribute separate terms via their
inner products with the old gradient. Measure these terms and old-query
ranks before and after A/B/C writes. Compare no replay, replay and
isolated Cells. Track absolute recall alongside retention ratios.

Wider/deeper MLPs cost more bytes and time. Low-rank changes reduce storage
but restrict the reachable updates. Independent Cells isolate writes and
increase routing and storage costs. Defer capacity expansion until a single
Cell clears content-sensitive retrieval.
