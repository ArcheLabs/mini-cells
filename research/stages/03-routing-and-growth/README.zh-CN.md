# 稀疏路由与生长：从细胞动力学到可独立修改的 Cell

**阶段问题：**Cell 能否成为状态可独立改变的路由计算单元？

实验 025/026、CLM upcycling、CLM-0.1、条件路由、CLM v2、CLM-0.3 渐进生长、边际效用、反事实/试用期 mitosis 和稀疏 runtime 推动了如下转变：

```text
生物类比中的 cell → 路由计算单元 → 可独立修改的模型状态
```

生长与路由得到实验支持，但启发式规则、计算成本和语义解释仍未解决。稳定稀疏路由、明确 Cell 粒度、可独立修改状态、事务候选和作为容量分配的生长进入核心验证；二维拓扑不是已验证机制的前提。
