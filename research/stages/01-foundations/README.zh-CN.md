# 基础：Echo、NCA 语言动力学与训练机制

**阶段问题：**为什么尝试细胞式语言动力学，NCA 的哪些性质可以迁移到语言？

实验 001–013 从 Echo 和基础可训练性推进到 1D/2D latent tissue、自适应停止、settling dynamics、稳定化成本和随机深度对照，形成了可复用的训练、评估与复现工具。

这些工作为细胞式语言动力学提供了历史实验支持，但扩展、稳定 settling 和训练效率仍有困难；局部动力学和二维 tissue 都没有证明真正的持续学习。进入下一阶段的是局部状态、重复计算、受控动力学和明确机制检验。
