## Proposed common task and adapters

Use a causal event stream with typed Write, Distractor and Query events. Derive token IDs and 32-dimensional Gaussian Key/Value directions from separate episode-local streams. Both branches receive the same events. E2 processes the complete token stream. The Titans adapter uses the declared Key/Value directions on Write and the matching Query direction on Query. Access target Value only during its Write and in the scorer. Make the mapping from event IDs to directions reproducible and independent of the episode assignments. Bind one query to a candidate bank for scoring without giving candidates or target labels to either branch.

Expose the E2 final-normalized hidden vector (256) via a verified pre-head adapter. Reuse the frozen weights and match adapter output through the original tied LM head against E2 logits. Titans Recall returns 32 dimensions. Concat gives width 288, with zeros for absent branches. A shared head design maps 288 to the 32-dimensional target representation (9,248 trainable parameters with bias). Train only small heads or approved input adapters on disjoint development seeds. Hold head fitting examples and updates constant. Log adapters, training identity and held-out episode hashes.

- S0 E2 hidden plus zeros. S1 zeros plus Titans Recall. S2 independent E2 and Titans branches with a common input and late concatenation. Verify that changing either dynamic state leaves the other feature unchanged. Measure overlapping execution separately on target hardware before claiming concurrency. Keep S2 dependency graph independent of CUDA scheduling.
- S3 forms the Titans Query from E2 hidden through a declared 256→32 adapter (8,224 parameters with bias). Count this conditioned path separately.
- S4 recalls from an initialized Cell with no association acquisition. S5 acquires the same memory as S2, then replaces Recall with zeros. Compare S5 against S2 with the same fitted head for the causal read-disable test. Fit protocol-matched heads separately for the main S0 and S1 comparisons.

Distance is measured in actual tokens from Write to Query. Select and freeze bins after measuring the event encoding. Use 0/8/32/128/256 distractors with reserved IDs and no target information. Mixed queries ask for an old binding and recent context, with per-component and joint scoring. S2 interaction comparisons require a zero-feature head baseline in addition to S0/S1. Use paired intervals, branch ablations and real cost before interpreting a gain as complementary information.

Gate B requires causal input/label checks, E2 feature parity, S0/S1 standalone correctness, S2 independent feature paths, S4/S5 effects and runtime/peak-memory accounting. These gates remain open.
