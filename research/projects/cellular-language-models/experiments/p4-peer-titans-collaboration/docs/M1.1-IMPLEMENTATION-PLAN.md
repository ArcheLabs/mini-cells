M1.0 initialize constructs NeuralMemory(256, 32, 64). The manifest confirms 32-dimensional FP32 latent inputs. M1.0 vectors uses QR through 32, switches to Gaussian for 64, and multiplies unit Values by sqrt(32). Its learn call repeats the complete episode 128 times. Recall@1 selects the maximum cosine over the candidate bank after read-only recall. Unknown FPR counts maximum candidate cosine >= 0.8.

Reuse initialize, tensor_hash, state_hash, read, checkpoint/restore and Gate 5. Add an explicit geometry argument to a new generator in the M1.1 directory. Sample independent Key and Value banks and random assignments from episode-local RNG. Normalize Gaussian rows at every size. Use QR only for N <= 32. Retain the shared sqrt(32) target scale to control for M1.0 write magnitude. Log normalized geometry statistics (within-Key, within-Value, cross-bank min/max/mean/SD), shapes, ordered hashes, permutation and seed. Use paired episode IDs across protocols and geometries.

Frozen learn accepts matching nonempty [batch,time,32] tensors including time=1. All rows in a chunk read the prior state. The squared error sums over features, averages over time, and sums over streams. Controls use the mean Key. Each call produces one Fast Weight/Momentum transition. Use width N, 1, 4 or 8, including a shorter final chunk. For each pass shuffle from an independent order seed, support reverse replay of the same schedule, and verify each association's actual presentations using index counters. Log processed presentations, update calls and elapsed time separately. Observe 4/8/16/32 seen-item prefixes on the first pass and full-episode checkpoints at exposure 8/32/64/128, then 256/512 on selected configurations. Score prefixes against explicitly labeled seen and full candidate sets.

For forgetting, use independent groups of four and acquire A/B/C, C/B/A and a reproducible randomized group order under the same exposure budget. At each boundary score all groups against the same candidate bank. Report raw Recall and retention relative to each group's first post-acquisition score, with zero-denominator retention undefined. Keep query and labels out of the update path during assessment.

Use 256 independent random unknowns and 256 hard negatives per episode. For QR, draw individual unknowns isotropically since the full known set can span the latent space. Generate hard negatives by mixing a known unit Key and a unit orthogonal residual at a frozen target cosine sampled in [0.80, 0.95]. Verify no exact collision, log actual cosines and hash the unknown sets. Report max-candidate cosine at 0.8, known rejection, correct accepted recall, unknown acceptance by category, precision under the declared known/unknown mix, and ROC/PR. Any adjusted threshold is selected on separate validation episodes and frozen before independent evaluation.
