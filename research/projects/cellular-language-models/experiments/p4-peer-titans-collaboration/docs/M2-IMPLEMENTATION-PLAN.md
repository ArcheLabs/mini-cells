# M2 implementation plan

Frozen m3/memory.py provides Cell, create, learn, fork, checkpoint, restore and state_bytes. Fast Weights and Momentum are the complete dynamic optimizer state. create clones expanded initializer tensors and allocates zero Momentum. online_adapt detaches inputs and Cell state, differentiates only the active Cell, then returns detached leaf Fast Weights and detached Momentum. There is no outer optimizer, retained update graph, stochastic update, KV cache or tokenizer in the latent execution path.

Use one frozen NeuralMemory instance per runtime. Record the static interface identity from static tensor hashes, constructor controls, source hash, architecture and latent interface version. This is the latent Memory interface. End-to-end Backbone and tokenizer sharing require a later model-level integration check.

Create A/B separately and compare equal initial tensor values, distinct IDs and disjoint underlying untyped storage across Fast Weights, Momentum and initializer. Recursively inspect nested mutable metadata and tensor containers. For each write direction assert exactly one step/revision increment, finite real parameter and Momentum changes, unchanged peer snapshot and bitwise-equal peer recall. Verify no static gradient or retained grad_fn. Check deterministic outputs on CPU.

Reuse M3 generation directories and atomic manifest writes. Add a strict peer inventory with independent root paths and a manifest digest per Cell, shape/dtype and source/provenance. Write the inventory last. Validate identity, expected names, batch/shape/dtype and file hashes before any cast or successful restore. M3 restore casts floating tensors to the initializer dtype, so a thin pre-cast dtype validator is needed. Validate architecture ID separately because it is metadata. Test missing Cell/component, corrupt JSON or tensor, wrong hash, architecture, static interface, shape and dtype. Shape/dtype fixtures must have consistent hashes so tests reach semantic validation.

Save A/B in a writer subprocess, terminate it, and use a new interpreter to restore each separately and both together. Compare exact state hashes and recall vectors on fixed queries. Restore A from disk, fork twice using M3 fork, verify inherited step and parent provenance and independent storage. M3 fork resets child revision to zero. Train the forks on distinct associations, verify untouched peer and parent, check branch-specific Recall, then persist and restore each fork in a new process.

Map T1–T20 to grouped tests for construction and aliasing, bidirectional updates, independent and fresh-process restore, fork divergence, and fail-closed fixtures. Measure Cell bytes, two-Cell and near-matched single-Cell bytes, write/read latency and checkpoint size. Tests and measurements are planned.
