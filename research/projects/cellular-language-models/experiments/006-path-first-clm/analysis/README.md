# Analysis contract

Run `research/projects/cellular-language-models/experiments/006-path-first-clm/implementation/analyze_experiment_006.py --source-commit SHA --seed SEED
--config CONFIG --output NEW_REPORT` against immutable arm archives. Omitting seed
aggregates the registered confirmation matrix. It reads reported statistics, not
sealed token assets, and never starts training.

All four arms, source/config/protocol/data/role identities and exact story/window
pairing are required. Paired bootstrap resamples story clusters, not independent
tokens. Exponentiated paired NLL confidence intervals give PPL ratio intervals.

Report R1/R0 state value, R2/R1 predecessor-prior value, and R2/M0 system quality /
executed GEMM / isolated cached latency separately. Report removal, deterministic
predecessor-row shuffle and same-operation-multiset order permutation separately.
Order permutation re-executes actual operations and preserves multiplicities; an
order effect alone does not demonstrate useful learned connections.

Frozen thresholds also check route collapse/unused Cells, context use and the
sampled-training/greedy-inference gap. Confirmation requires every registered seed
and consistent source/contract/data identities. A positive mechanism with an
uncompetitive M0 comparison yields `PATH_MECHANISM_SIGNAL_ONLY`, never a system
superiority claim. Scientific booleans remain false until research review. R3
compute adaptivity is always unsupported in this implementation.

Large weights/corpus belong in separately approved storage. Git archives store
only identities, content hashes, per-story statistics, telemetry and failure records.
