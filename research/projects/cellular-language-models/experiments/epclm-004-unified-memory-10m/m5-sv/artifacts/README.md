# Runtime artifacts

The Notebook writes frozen datasets, manifests, training metrics/checkpoints, gate records,
scientific summaries and English reports to its Kaggle Output. Detailed per-query traces
and model/runtime binary checkpoints are retained there. Git publication contains curated
metadata, per-Episode summaries and hash manifests, never binary weights or the sealed Test
input bank. Attach the complete prior saved Output to resume exact-identity work.

No T4 scientific results are pre-populated in this repository directory.
