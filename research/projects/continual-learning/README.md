# Continual Learning

This project investigates whether learned systems can acquire new behavior
without unacceptable loss of prior capabilities. It contains the former
continual-learning research line, including mechanism studies, validation
experiments, and negative results.

## Contents

- [`context/`](context/) preserves the original research-stage records.
- [`experiments/`](experiments/) contains experiment-owned protocols,
  implementations, reports, and available results.

## Reading results

Consult each experiment's README and frozen validation record before interpreting
an outcome. Mechanism-level evidence is not automatically evidence of
model-level continual learning.
