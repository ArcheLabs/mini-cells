# Core 009A Implementation Notes

009A is intentionally function-first: heldout local-action residual is the support target. Matrix-space Frobenius residual, factor spectra, one-sided projections, and the full `(m,n)` landscape are diagnostic only. This avoids rejecting a geometry that preserves the actual Cell action on sequence activations while differing in matrix directions those activations do not exercise.

The frozen protocol must be updated consistently before any discovery seed is run if this note and the protocol disagree. After the first discovery seed is opened, no gate or threshold changes are permitted.
