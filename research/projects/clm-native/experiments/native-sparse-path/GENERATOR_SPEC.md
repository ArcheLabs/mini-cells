# Generator and solver specification v1

An instance exposes only `x[N,10]`, `candidates[N,8]`, root addresses, task type and a common task-defined number of rounds. Features: two scales, two biases, two routing keys, a unique static priority, two initial values and root role. Roots do not carry labels or a correct route. Topology is built using split/template seeds before continuous values are generated/solved. Candidate positions and physical addresses are randomized; static-candidate subcondition deliberately uses one fixed absolute template across splits and removes physical permutation; values and instance seeds remain disjoint. This subcondition tests static computation, not topology OOD.

For A/B, source message is tanh(scale_source * resident_value + bias_source). Among eight provided candidates choose the highest inner products with each candidate's visible two-dimensional key. A sends one message; B sends two messages each divided by two. Keep at most eight unique recipients by their immutable unique priority. Recipient state becomes tanh(0.3*old_value + summed incoming messages), from a synchronous old-state snapshot. Other values remain unchanged. B revisits nodes and merges branch histories. Its final result is the sum of resident values multiplied by visible readout keys, normalized by sqrt(frontier size), to avoid a trivial zero/average-collapse target. A reads the final value. C uses the identical dynamics but follows smallest static priority (one edge), so state-dependent routing is unnecessary.

The model learns continuous hidden states and message/update functions, not the analytic executor. The analytic operation/routing rules are public to all baselines, and ALG executes A exactly; learning this task cannot establish superiority to that algorithm. Supervised training receives final two-dimensional answer only. Route/trajectory labels are not used.

Train seeds 100000..199999, dev 200000..299999, sealed 300000..399999, OOD 400000..499999 (task-specific nonoverlapping offsets). Template IDs are split base + index modulo 64. Path templates and value seeds differ between splits. For A/C, physical layers are construction devices, hidden from learned feature inputs, not a fixed architectural backbone; addresses are permuted. B candidates form directed, cyclic arbitrary-address graphs. Task generator is not a claim about natural-language reasoning.

The reference NumPy solver and a separately written literal Torch executor agree on deterministic fixtures. Duplicate input IDs are checked. Sealed generation is inaccessible until a reviewed final-checkpoint lock. M2 includes a trained global mean/root-pool network and zero-predictor tests; solving B by those shortcuts is an IMPLEMENTATION_FAIL of the task design, not a reason to increase model capacity.
