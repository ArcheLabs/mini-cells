# CLM Native — bounded dynamic sparse paths

Research question: can state-dependent nonlocal Cell communication improve quality and actual cost over information-matched recurrent and centralized controllers?

This is a self-contained research project. Start with [the experiment](experiments/native-sparse-path/README.md), [preregistration](experiments/native-sparse-path/PREREGISTRATION.md), and [prior evidence](experiments/native-sparse-path/PRIOR_EVIDENCE.md). This synthetic computation study does not claim language-model capability or 10× LLM efficiency. CLM-Bridge expensive follow-up training remains paused; it is not a dependency.
