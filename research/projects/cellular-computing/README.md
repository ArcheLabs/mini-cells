# Cellular Computing

This project studies computation built from interacting Cells: how useful
capabilities form, how work is routed and grown, and when sparse execution is
effective. Its history includes the early foundations, self-organization, and
routing-and-growth research lines.

## Contents

- [`context/`](context/) preserves the original stage records as historical
  context. These records remain unchanged in meaning and are not separate
  current projects.
- [`experiments/`](experiments/) contains the experiment units owned by this
  project. Each experiment keeps its own protocol, implementation, reports, and
  results when those materials exist.

## Reading results

Use each experiment's README and frozen protocol as the authority for its
hypothesis, status, and decision. The shared research registry is an index, not
a replacement for those records. Failed and superseded work remains part of the
evidence history.
