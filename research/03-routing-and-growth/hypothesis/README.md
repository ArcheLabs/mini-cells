# Sparse Routing and Growth: From Cellular Dynamics to Independently Mutable Cells

**Stage question:** Can a Cell become a routed computational unit whose state can change independently?

Experiment 025/026, CLM upcycling, CLM-0.1, conditional routing, CLM v2, CLM-0.3 progressive growth, marginal utility, counterfactual/probationary mitosis, and sparse runtime work shifted the project from biological analogy to operational model structure:

```text
cell as biological analogy
→ cell as routed computational unit
→ cell as independently mutable model state
```

Growth and routing gained empirical support, but heuristics, compute cost, and semantic interpretation remained unresolved. What survived was stable sparse routing, explicit Cell granularity, independently mutable state, transactional candidates, and growth as capacity allocation. A literal 2D topology did not emerge as a prerequisite.

Canonical evidence includes [`clm-0.3-progressive-growth`](../../../artifacts/experiments/clm-0.3-progressive-growth), [`clm-0.3b-marginal-growth-utility`](../../../artifacts/experiments/clm-0.3b-marginal-growth-utility), and [`clm-0.3d-probationary-mitosis`](../../../artifacts/experiments/clm-0.3d-probationary-mitosis). Historical documents remain in [`sources/`](sources/).
