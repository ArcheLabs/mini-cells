# Experiment 024 Diagnosis

## Summary

Experiment 024 did not produce the preregistered sequential `1 -> 2 -> 3` signal. Its authoritative status remains:

`FIRST_BIRTH_WITHOUT_SECOND_TRAIT_GENESIS`

The important diagnosis is that this outcome is not well described as a generic failure of the probationary birth rule. The first Story/Arithmetic bifurcation is supported, the null and duplicate/weak controls behave correctly, and the missing second birth is associated with strong positive transfer from the already-emerged computational trait to the planned Transform benchmark.

## What succeeded

- Story-only proposal rejected in 3/3 replicates.
- Story/Arithmetic first birth passed the full preregistered gate in 2/3 replicates.
- Duplicate-Arithmetic proposal rejected in 3/3 replicates.
- Weak-Transform proposal rejected in 3/3 replicates.
- Existing two-trait Story/Arithmetic identity was retained across the negative-control stages.

## What failed

The strong Transform stage did not pass the full second-birth gate in any replicate. One replicate committed a third branch by prospective utility, but that three-branch system failed the preregistered three-domain functional-identity and routing-purity requirements. Only 1/3 replicates ended at K=3.

## Transfer evidence

The post-birth computational branch is not narrowly Arithmetic-specific. It also improves the held-out Transform benchmark substantially.

Replicate 0 at Stage E provides a clear example:

- computational branch Arithmetic improvement versus frozen parent baseline: about `+1.091` NLL;
- computational branch Transform improvement versus frozen parent baseline: about `+1.367` NLL.

The same qualitative pattern appears in replicates 1 and 2. Therefore the organism has learned a division closer to:

- Story / natural-language-preserving trait;
- synthetic-computational sequence-processing trait;

rather than three benchmark-name traits: Story / Arithmetic / Transform.

## Proposal and probation evidence

At Stage E, the K=2 -> K=3 proposal residual gain varies strongly by replicate. Replicate 0 shows almost no additional geometric structure, while replicates 1 and 2 show larger residual gains. Only replicate 1 turns that proposal into sustained positive prospective utility and commits a third branch. However, the resulting routing purity is below the preregistered threshold and the three-domain identity test fails.

This distinction matters:

`geometric secondary structure != independently necessary functional trait`

and:

`positive prospective utility alone != stable semantic trait identity`

## Scientific interpretation

The benchmark label is not the trait boundary. A task can look semantically new to the experimenter while still being absorbable by an existing phenotype basis.

A better developmental criterion for a third trait is therefore not simply whether the data belong to a new named benchmark. It is whether existing traits can absorb the new demand without creating sufficient counterfactual value for a new phenotype.

We summarize the result as:

`task label != natural expert boundary`

and propose the stronger notion:

`expert boundary = functional non-substitutability under developmental pressure.`

## Consequence for Experiment 024b

Experiment 024b should screen candidate third capabilities for independence before using one in the final sequential birth challenge. Screening should identify a candidate for which adaptation of the existing computational trait gives little or negative transfer while the candidate still has learnable signal. The candidate-selection rule must be preregistered and deterministic, and the final birth experiment must keep the 023b/024 structural-cost and geometry-advantage thresholds unchanged.

This diagnosis changes interpretation, not data. `decision.json`, raw CSVs, checkpoint manifests, and the Experiment 024 status are intentionally unchanged.
