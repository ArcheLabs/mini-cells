# Pre-0.4 Research Archive

This directory preserves the audit trail for the consolidation. [`branch-manifest-pre-0.4.json`](branch-manifest-pre-0.4.json) records every non-`main` remote branch before cleanup, including ancestry, unique commit count, artifact preservation, classification, and disposition. [`legacy-path-map.csv`](legacy-path-map.csv) maps every moved top-level research document or protocol to its canonical destination.

The manifest is generated by [`scripts/maintenance/build_pre_0_4_branch_manifest.py`](../../scripts/maintenance/build_pre_0_4_branch_manifest.py). It is an audit and indexing utility only; it never deletes refs or changes scientific artifacts.
