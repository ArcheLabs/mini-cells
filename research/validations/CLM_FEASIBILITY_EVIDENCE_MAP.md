# CLM Feasibility Evidence Map

Status: **FROZEN v1.6 — CONSTRUCTIVE CORE CLOSED**  
Constructive baseline through formal CLM-005 result, protocol `3188e56af52763d2de75e4d13f25c5cbff2e56b25d5b32520495148e5e65b27d` (2026-09-02).

## Purpose

This map prevents MiniCells from repeatedly re-testing mechanisms that are already supported, falsified, or bounded by earlier work.

The product/research path remains:

```text
pretrained LLM
  -> external CLM layer
  -> hybrid CLM
  -> endogenous / Native CLM
  -> Small Native CLM v0 training
```

The Native route no longer depends on discovering a ready-made Cell ontology inside a pretrained checkpoint. The Constructive CLM sequence established, under registered controlled worlds, that learned Cell coordinates can be formed, grown, protected, composed and governed by learned control.

## Evidence grades

- **A — formal:** frozen multi-seed or otherwise registered scientific decision.
- **B — controlled:** repeatable mechanism evidence, but not a complete continual-learning decision.
- **C — diagnostic:** useful bridge/geometry evidence; not sufficient as a standalone CLM claim.
- **Open:** not established by the repository.

## Explicit no-repeat list

Do not create a new core validation whose primary question is only one of the following:

1. Can Cells grow?
2. Can growth restore plasticity?
3. Can Cells be independently mutable?
4. Can sparse routing exist?
5. Can conflict induce differentiation?
6. Can bounded Cell-local subspace state protect registered history without replay?
7. Do real Pythia representations contain any reusable low-dimensional structure?
8. Is the common carrier causally useful?
9. Is semantic routing address automatically the functional split boundary?
10. Is the same pretrained effect geometry secretly sparse/local under another near-equivalent fixed dictionary?
11. Can the registered 001 world form six Cells again?
12. Can the registered additive 001B world recover the same six latent Cells again?
13. Can the registered 002 synthetic growth curve be reproduced merely by extending the horizon?
14. Can the registered 003 certificate-growth world reproduce the same protected-write result under cosmetic changes?
15. Can the registered 004 linear-operator world reproduce the same multi-Cell composition result with more synthetic cases or Cells?
16. Can the registered 005 learned-control world reproduce the same result with more synthetic Cells, repeats, or horizon?

A new experiment touching these topics must name a genuinely new integration variable.

## Research stop / transition rule

The previous Native-route stop rule required repeated constructive failure across coordinates, read/write alignment, bounded growth, replay-free protection, model-level composition and scaffold removal. G1–G5 are now formally supported under their registered boundaries, so that stop rule is no longer the active question.

The program now transitions from **mechanism feasibility** to **trained-model feasibility**.

The next falsifiable questions belong to Small Native CLM v0, for example:

- can a token-predictive model learn the Cell substrate rather than receiving the synthetic decomposition;
- can learned Cell routing/write/growth survive nonlinear sequence modeling;
- can the system retain useful continual-learning behavior on language-like streams;
- what compute/state scaling laws emerge when Cell dynamics are trained jointly with prediction.

## Product boundary

External CLM Layer feasibility and Native CLM feasibility remain separate decisions. The supported constructive Native route does not invalidate the near-term product path: engineered persistent Cells, routing, certificates, growth, versioning and rollback can still be deployed on top of mature LLMs before endogenous CLM is ready.
