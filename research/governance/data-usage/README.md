# Global content exclusion registry

Implementation: `shared/python/minicells_data_registry`. It performs pure CPU SHA256 content indexing and deterministic content-ranked selection. SQLite rows retain method, hash, source, role and raw index; no raw story text is saved. R3m Amendment003 is the first partial import, not a claim of complete historical coverage.

Claims remain immutable in the imported ledger. Missing Revision, ambiguous filtered indices, unbounded reservations and missing window identities are UNKNOWN. A conservative content union can exclude more records than actually used; it cannot verify an individual historical declaration. Never convert UNKNOWN into a clean release. New users must call the independent release gate with verified coverage, exact tokenizer, windows and scientific review.

Current proof and complete claim provenance: `research/projects/cellular-language-models/experiments/clm-001-qfirst-integrated/r3m/registration/amendment-003/`. Large index identity, byte size and local availability are recorded there. No HF durability is claimed. Rebuild or recover the exact index by hash before reuse on another machine. The index is not a replacement for original snapshot/loader/window evidence.

Adoption remains append-only. Import newly recovered evidence as a new revision of coverage; preserve failed amendments. Main/Confirmation content is audit-only and must not be handed to models. Existing historical scientific identities stay unchanged.
