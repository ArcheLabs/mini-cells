# Kaggle Execution

Research experiments that use Kaggle keep their Notebook and run instructions
inside the experiment's project directory. This page documents only the shared
tool location.

Reusable Kaggle submission, collection, and asset helpers are under
[`shared/kaggle/`](../../shared/kaggle/). The experiment remains responsible
for its source commit, configuration, protocol gates, and result identity.

Before running a notebook, read its experiment README and frozen protocol.
Never treat a development run or a successful upload as scientific
confirmation.
