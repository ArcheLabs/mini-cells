# Tutorials

This directory contains general product tutorials, not canonical research
experiments.

- [`hybrid-clm/`](hybrid-clm/) contains HybridCLM quickstarts.
- [`kaggle-launchers.md`](kaggle-launchers.md) summarizes the shared Kaggle
  execution helpers.
- [`colab.md`](colab.md) records the Colab tutorial entrypoint.

For a research run, use the Notebook and instructions stored in the owning
experiment under [`research/projects/`](../../research/README.md).
