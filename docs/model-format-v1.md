# Model Format V1

Echo V0 has exactly 4,476 signed 16-bit Q8.8 parameters (8,952 little-endian bytes): token embeddings for a 44-symbol vocabulary, local recurrent cell weights for 64 cells with radius 2, and an output projection. Embedding width is 8, hidden width 16, MLP width 32, and recurrent iterations 4. Maximum sequence length is 32.

Arithmetic is deterministic saturating integer arithmetic. Multiplication rounds back to Q8.8; activation and reductions use the fixed kernel in `minicells-core`. Model hashes are BLAKE2b-256 over the `mini-cells:model:v1` domain followed by canonical parameter bytes.

Genesis is generated by SplitMix64 with seed 1 and values in `[-16, 16]`. Its canonical hash is `0x0af6953731041b3612fdcb3cc481a09d501d9bfe4d8401279d02831232ff2fd2`. Training uses deterministic batches, integer margin evaluation, symmetric perturbations of 4 Q units, and a one-Q-unit SIGN-SPSA update.
