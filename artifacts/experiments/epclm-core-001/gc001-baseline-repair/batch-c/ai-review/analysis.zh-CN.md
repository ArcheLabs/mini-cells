## AI 辅助评分方法

每条样本分别评价六个既有维度：语法、局部连贯、语义一致、提示相关、故事推进、重复退化。每项 1–5 分，越高越好。重复退化分数越高表示重复越少，不代表文本整体更好。

评分锚点：1=该维度严重失效；2=少量可辨认结构但明显不足；3=部分满足、仍有明显错误；4=多数满足、有局部缺陷；5=该维度清楚满足。语法单独判断句子结构，因此不断重复一个合语法句子的输出可以语法较高、故事推进和重复两项最低。极短乱码没有重复可以重复项较高，但其他维度仍最低；不能用六项简单平均掩盖这一点。此锚点为事后辅助评审口径，不是预注册的成功阈值。

我逐条阅读了 256 个匿名 ID 的提示与续写，并显式指定各条六项评分。对第 33–256 条中的连续重复子串使用可逆重复计数显示以节省阅读量，未删去非重复内容。评分不是由自动重复率或 PPL 映射生成。

**限制**：只有一个 AI 评审者，且已事先阅读模型汇总结果，不能称为严格独立盲评。匿名 ID 隐去了逐样本模型归属，但模型特征可能可辨认。没有评审者间一致性估计，也没有两个独立人工评审者。结果不应输入 `human-review-scored.csv`，不得据此把 Batch C 标记为人工盲评 COMPLETE。

评分冻结后，用原报告中的精确“提示＋续写”文本关联模型。存在重复文本，已核对同提示同文本的所有评分完全一致，因此均值不依赖这些 ID 的未解析分配。未使用私有盲评密钥。

### Greedy 输出

所有模型的贪心续写都出现严重退化，16/16 条均未在 128 Token 上限内生成 EOS。C1-BROADCAST/IC/Flat 的重复 3-gram 率分别约 93.45%/93.85%/93.06%，T1 约 88.74%。

T1 的区别是有些循环单位是近似完整句子，例如 S0020 的“He was so happy.”反复出现；其他模型更多是“He/he”“They”“her”“and”等词片段循环。T1 贪心语法均分 3.63，但故事推进和少重复均为 1.00。**这说明语言形式有所改善，不等于解决生成退化。**

## 状态诊断

C1-BROADCAST 和 IC-ALL-SELF 的已有自由生成轨迹中，非零 Cell 均为 16，故“Independent 只用了一个 Cell”的旧问题不适用于本轮新对照。

- C1-BROADCAST 的跨 Cell 平均余弦相似度范围约 [−0.054, 0.077]，最大 pair 相似度约 0.331；IC 对应约 [−0.056, 0.075]、0.413。未观察到接近全同的 Cell 表征。不同坐标滚动注入本身也会造成差异，因此这种多样性不证明语义分工。
- 已记录轨迹的数值边界接近度最大约 0.039–0.040，即约注册最大绝对值阈值的 4%；训练曲线梯度和 Loss 记录有限。没有看到本轮 NaN/Inf 或接近该数值阈值的证据。
- C1/IC 的逐 Token State 变化范数约 38–52，状态仍在变化。输出循环不能直接等同于内部状态严格固定点；也不能排除读出层重复、低维动力学或其他退化。
- T1 的状态容器保存 Token 上下文，它的范数不能和 Cellular 浮点潜在状态范数作语义比较；Flat 切块也不是具有语义的 Cell。

**仍缺失的关键证据是：这些状态是否保存了对回答有用的特定历史。** 现有指标没有同一问题、同一后缀下的历史交换、State Reset、历史删除、查询/延迟配对干预，无法识别有用记忆是否存在。不能以“16 个 Cell 非零”或状态持续变化替代该证据。

## EOS 与校准

验证集中真实 EOS 目标只有 16 个。C1/IC/Flat 的 EOS 目标平均预测概率约 0.73%/0.70%/0.92%，T1 约 8.59%；四者 EOS 目标 Top-1 命中均为 0。T1 对 EOS 的目标概率更高，但贪心仍未停止，生成退化并非仅靠提高终止概率就已解决。

C1/IC/Flat 的验证 Token Top-1 准确率约 9.27%/9.00%/9.45%，T1 约 23.63%。Cellular 的低置信度与较小 ECE 不应被解释为更强或更可靠；应结合准确率、NLL、EOS 稀少性和分箱占用一起看。
