# Changelog

## 0.2.0a1 — HybridCLM prerelease

- Added the public `HybridCLM`, `CellPlacement`, `CellMutation`, and
  `ModelInspection` API.
- Added the fail-closed Granite MoE backend and safetensors mutation schema.
- Added alpha scaling, attach/detach, zero-state and restoration reports.
- Consolidated deterministic fixtures under `tests/fixtures/` and archived
  CLM-0.4 documentation without rewriting historical evidence.
- Formal HybridCLM execution remains not started.
