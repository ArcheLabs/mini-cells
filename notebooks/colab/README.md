# Colab launchers

Colab launchers follow the same boundary as Kaggle launchers: notebooks bootstrap and orchestrate; canonical experiment logic remains under `scripts/research/` and frozen scientific contracts remain under `research/validations/`.

No formal Colab launcher is currently required for MoE Mutation 001. Add one only when Colab provides a concrete execution advantage or a second-platform replication is part of a frozen protocol.
